# 🤖 AI Sales Assistant (B2B Telegram Bot)

Умный ассистент для отдела продаж, который экономит время менеджеров и берет на себя рутину. Бот использует современные LLM и технологию **Tool Calling (Function Calling)** для взаимодействия с внутренними системами компании.

## 💡 Бизнес-ценность
Менеджеры по продажам тратят до 30% времени на переключение между CRM, почтой и мессенджерами. Этот бот становится единым окном:
*   **Мгновенная сводка по лидам:** Больше не нужно искать данные в таблицах. Бот сам обращается к базе и выдает список горячих клиентов.
*   **Генерация follow-up писем:** Бот пишет персонализированные письма клиентам на основе контекста.

## ⚙️ Ключевые фичи
*   **Tool Calling:** Нейросеть (Gemini) анализирует запрос пользователя и **сама решает**, когда нужно вызвать функцию для получения данных, а когда просто ответить текстом.
*   **Современный асинхронный стек:** Написан на Python с использованием `aiogram 3`.
*   **Защита данных:** Все ключи хранятся в переменных окружения (Environment Variables).

## 🛠 Стек технологий
*   **Python 3.10+**
*   **aiogram 3** (Асинхронный фреймворк для Telegram)
*   **Google Gemini API** (LLM с поддержкой Function Calling)
*   **python-dotenv** (Управление переменными окружения)

## 🚀 Как запустить локально

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/olgatazkorob7-png/b2b-sales-ai-bot.git
   cd b2b-sales-ai-bot
Установите зависимости:

bash
pip install -r requirements.txt
Создайте файл .env в корне проекта (на основе .env.example) и добавьте ваши ключи:

env
BOT_TOKEN=ваш_токен_от_BotFather
GEMINI_API_KEY=ваш_ключ_от_Google
Запустите бота:

bash
python main.py
📈 Примеры использования
"Дай сводку по лидам на сегодня" — бот вызывает функцию get_crm_leads() и красиво оформляет ответ.

"Напиши письмо Ивану. Он хочет скидку 10%, но сомневается в бюджете" — бот сгенерирует профессиональный текст письма.
